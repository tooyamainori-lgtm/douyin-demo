# 架构设计文档

## 系统架构

```
┌─────────────────────────────────────────────────┐
│                    前端 (Vue3)                    │
│           SPA — 运行在浏览器 / WebView            │
└─────────────────────┬───────────────────────────┘
                      │ HTTP / Axios
                      ▼
┌─────────────────────────────────────────────────┐
│                Nginx (反向代理/静态资源)            │
└─────────────────────┬───────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────┐
│              后端 (Spring Boot 3)                 │
│   Controller → Service → Mapper                  │
│   ├── 认证: JWT 无状态                            │
│   ├── 缓存: Redis                                 │
│   ├── 存储: MinIO                                 │
│   └── 数据库: MySQL 8                             │
└─────────────────────────────────────────────────┘
```

## 分层职责

| 层 | 职责 | 禁止 |
|------|------|------|
| Controller | 接收请求、参数校验、调用 Service、返回 Result | 写业务逻辑 |
| Service | 业务逻辑编排、事务管理 | 直接操作数据库 |
| Mapper | 数据库操作（继承 BaseMapper） | 写业务逻辑 |

## 核心模块

1. **用户模块** — 注册/登录/个人信息/JWT 认证
2. **视频模块** — 发布/播放/信息流推荐
3. **互动模块** — 点赞/评论/分享/关注
4. **搜索模块** — 用户搜索/视频搜索

## 数据流

```
用户请求 → Filter(鉴权) → Controller(参数校验)
    → Service(业务逻辑) → Mapper(数据操作)
    → 组装 VO → Result.ok(vo) → JSON 响应
```
